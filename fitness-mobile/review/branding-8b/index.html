Somata / Foundation + Home utilities

Actual React Native JSX rendered offline through React Native Web. Synthetic records, inert service fixtures, no Firebase or personal data. Browser previews are not native screenshots: safe areas, keyboard, permissions, gestures and VoiceOver require a device. Native validation/save failures still use system alerts; no new Calendar loading/error state has been invented.

Before captures use the original source snapshot; after captures use current source. Legacy water is the unchanged control. Narrow/large-text pages approximate 1.8× font scaling.
